# Reklamní předměty a tapety Depo

Exporty z plátna Claude Design „Depo — reklamní předměty a tapety".

- `png/` — rastrové exporty ve dvojnásobném rozlišení (2×).
- `svg/` — exporty jako SVG. Obsahují vložený HTML obsah (`foreignObject`) a písma Archivo a JetBrains Mono se načítají z Google Fonts, takže se správně zobrazí v prohlížeči. Pro tiskárnu nebo Illustrator je spolehlivější PNG.

Zástupné texty jsou v hranatých závorkách, například `[NÁZEV AKCE]`.
