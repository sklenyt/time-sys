# time-sys

Moderní webová náhrada desktopové aplikace **Časomíra** (MS Access) pro měření časů sportovních závodů — offline-first, se síťovou spoluprací mezi stanovišti a živou publikací výsledků.

Projekt je zatím ve fázi analýzy a návrhu architektury (kód aplikace ještě neexistuje). Kompletní dokumentace: **[docs/00-index.md](docs/00-index.md)**.

UI mockupy klíčových obrazovek: [docs/07-ui-mockups.md](docs/07-ui-mockups.md) (zdroj v [design/mockups](design/mockups)).
